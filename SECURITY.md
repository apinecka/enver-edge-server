# Security policy

## Reporting a vulnerability

Please tell us privately before you publish anything, through either channel:

- [Report a vulnerability](https://github.com/apinecka/enver-edge-server/security/advisories/new) on GitHub (private), or
- e-mail [tomcupak@gmail.com](mailto:tomcupak@gmail.com?subject=Security) with "Security" in the subject.

Describe what you found, how to reproduce it and what it lets an attacker do. We confirm receipt within 3 working days and keep you posted until it is fixed. We fix critical issues as fast as we can and aim for 90 days at most otherwise. Once it's fixed, we are happy to credit you, unless you prefer to stay anonymous.

This covers the agent in this repository and also the Enver service it talks to (the app and the API). The full policy, including the rules for testing against the service, is at [enver.apinecka.com/about/contact/#security](https://enver.apinecka.com/about/contact/#security). In short: test only against your own account and edge servers, don't access or change other users' data, and don't run denial-of-service or social-engineering attacks. Research done in good faith under these rules is welcome, and we won't take legal action against it.

## Supported versions

Only the latest release is supported. Installed agents update themselves unless automatic updates are turned off.
